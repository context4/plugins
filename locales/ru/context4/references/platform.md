# Платформа

Используй существующую модель идентификации приложения, tenant, авторизованный путь выполнения и модель/фреймворк. Прочитай [совместимость SDK](https://ctx4.me/docs/composio-sdk.md) перед выбором пакета и версии. Base URL Composio SDK: `https://ctx4.me/compat/context4/v1`; нативный API: `https://ctx4.me/v1`.

Прочитай [OpenAPI](https://ctx4.me/docs/openapi.json) и [compat-маршруты](https://ctx4.me/docs/compat-routes.json). Получай учётные данные штатным механизмом секретов приложения; никогда не проси их и не выводи в чат. Не запускай Composio login/dev-init, не создавай облачный проект Composio, не вводи Context4 SDK/CLI и не копируй возможности, доступные только в облаке Composio.

У сессий, proxy, ошибок и идентификаторов есть собственные документированные форматы. Сохраняй user IDs и сопоставление аккаунтов; никогда не используй одного демонстрационного пользователя для разных tenants. Создавай auth configs, только если интеграция действительно этого требует. Проверяй запрошенную интеграцию через реальный путь выполнения, когда пользователь разрешил эту операцию; одна документация не является доказательством.

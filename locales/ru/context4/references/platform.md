# Платформа

Используй существующую модель идентификации приложения, tenant, авторизованный путь выполнения и модель/фреймворк. Прочитай [совместимость SDK](@@CONTEXT4_DOCS_ORIGIN@@/docs/composio-sdk.md) перед выбором пакета и версии. Base URL Composio SDK: `@@CONTEXT4_COMPAT_URL@@`; нативный API: `@@CONTEXT4_API_ORIGIN@@/v1`.

Прочитай [OpenAPI](@@CONTEXT4_DOCS_ORIGIN@@/docs/openapi.json) и [compat-маршруты](@@CONTEXT4_DOCS_ORIGIN@@/docs/compat-routes.json). Получай учётные данные штатным механизмом секретов приложения; никогда не проси их и не выводи в чат. Не запускай Composio login/dev-init, не создавай облачный проект Composio, не вводи Context4 SDK/CLI и не копируй возможности, доступные только в облаке Composio.

У сессий, proxy, ошибок и идентификаторов есть собственные документированные форматы. Сохраняй user IDs и сопоставление аккаунтов; никогда не используй одного демонстрационного пользователя для разных tenants. Создавай auth configs, только если интеграция действительно этого требует. Проверяй запрошенную интеграцию через реальный путь выполнения, когда пользователь разрешил эту операцию; одна документация не является доказательством.

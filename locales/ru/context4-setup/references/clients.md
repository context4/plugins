# Выбор инструкций клиента

Загрузи одну пару, а не все клиенты:

| Клиент | Настройка MCP/плагина | Установка скиллов |
| --- | --- | --- |
| ChatGPT | [ChatGPT](https://ctx4.me/docs/connect-chatgpt.md) | [Скиллы ChatGPT](https://ctx4.me/docs/skills-chatgpt.md) |
| Claude web/desktop | [Claude](https://ctx4.me/docs/connect-claude.md) | [Скиллы Claude](https://ctx4.me/docs/skills-claude.md) |
| Codex | [Codex](https://ctx4.me/docs/connect-codex.md) | [Скиллы Codex](https://ctx4.me/docs/skills-codex.md) |
| Claude Code | [Claude Code](https://ctx4.me/docs/connect-claude-code.md) | [Скиллы Claude Code](https://ctx4.me/docs/skills-claude-code.md) |
| Hermes | [Hermes](https://ctx4.me/docs/connect-hermes.md) | [Скиллы Hermes](https://ctx4.me/docs/skills-hermes.md) |
| OpenClaw | [OpenClaw](https://ctx4.me/docs/connect-openclaw.md) | [Скиллы OpenClaw](https://ctx4.me/docs/skills-openclaw.md) |

ChatGPT web требует плагин; сохранение файлов в каталоге Codex не устанавливает его там. Загрузка ZIP в аккаунт Claude отличается от локальных файлов Claude Code. Один скилл не подключает MCP.
